# SKYHAUL — Island Freight Run

An original pseudo-3D flight game for the [make.fun best-flight-game-20261126-0057 bounty](https://make.fun/bounty/best-flight-game-20261126-0057): take off from a grass strip on a seeded island, thread seven glowing rings over patchwork fields, a winding river and the coast, then come home and land for a graded score. Hand-rolled 3D projection on a 2D canvas — no libraries, no assets, no network; every pixel and every sound is generated by the game's own code.

## The game

- **Two views**: a chase view with a stylised low-poly aircraft (banking airframe, prop blur, nav lights, ground shadow), and a cockpit view (V) with a full lit instrument panel — attitude indicator, airspeed with stall arcs, altimeter, compass strip, vertical speed, throttle quadrant, fuel gauge and STALL / GEAR / FUEL warning lights.
- **A real flight model**: throttle and fuel burn, lift and stall with nose-drop, coordinated bank-to-turn, energy trading between climbs and dives, ground roll and rotation, landing graded SMOOTH / FIRM / HARD by sink rate, alignment, gear and touchdown speed.
- **A living island**: patchwork fields at true terrain heights, a river running to a bay, roads, villages, 300 trees, nine snow-capped peaks (they are solid — the collision model knows their height), drifting clouds, sun and haze.
- **Complete loop**: title screen over a live autopilot attract flight, controls briefing, pause, results screen with a grade letter and score breakdown, restart. Procedural WebAudio sound throughout: engine by throttle, wind by speed, ring chime, touchdown thud, stall warble.

## Controls

Pitch and roll with the arrow keys or WASD · throttle with Shift / Ctrl (or PgUp / PgDn) · G landing gear · V cockpit / chase view · P pause · M sound · R restart.

## How it works

`main.ts` (Node 22, standard library only) hands the entry in: it copies `game/` and `screenshots/` to the output directory and writes `dossier.json` with the vendored make.fun library in `vendor/makefun-game.ts`.

```sh
node main.ts            # writes /output (or $MAKEFUN_OUTPUT_DIR)
```

To play locally, serve `game/` with any static file server and open `index.html` in a desktop browser — it plays fully offline.
